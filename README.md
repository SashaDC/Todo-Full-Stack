 Full-Stack Todo Application

My first complete CRUD todo app built to practice full-stack development with React Query and SQLite.

## Features
- Add, edit, delete tasks
- Mark tasks complete
- Priority levels
- Persistent SQLite database

## Tech Stack
- **Frontend:** React, TypeScript, TanStack Query
- **Backend:** Express, Knex.js, SQLite

## What I Learned
- React Query for server state management
- Database design and migrations
- RESTful API design
- Full-stack CRUD operations

## API Endpoints
```
GET    /api/v1/tasks
POST   /api/v1/tasks
PUT    /api/v1/tasks/:id
DELETE /api/v1/tasks/:id
```
